# 0011 - hq is written in Go

hq is one executable in four roles: the CLI, the list program, the dialogs inside tmux popups, and the internal commands behind the Alt chords, which start a new process on every key press. Go gives a single static binary per platform (one-command install, no runtime on the machine), a start-up of a few milliseconds (chords feel instant), cross-compilation for macOS arm64/amd64 and Linux (WSL) from one machine, and a mature terminal UI library (Bubble Tea). It is plain enough for agents to write well and for the owner to review quickly.

## Considered Options

- **Rust**: equally good binary and start-up; slower to write and review, cross-compilation more involved.
- **Python (uv)**: easy to write; needs uv and a managed Python on every machine, and 60-150 ms start-up per chord.
- **Bash** (the removed prototype): no terminal UI, fragile at this size.

## Consequences

- The project template's stack-specific pieces (pyramid check, tests workflow, local-dev, `bump-version.sh`) are ported to Go when the first code lands; the version comes from the git tag through build flags, so `bump-version.sh` keeps writing nothing.
