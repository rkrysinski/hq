So for every reason of equivalence in the pull request's `## QA` (`gh pr view [-<pr>-]{+PR+} --json [-body`),-]{+body` with PR its number),+} in every mutation block whatever its base, the reviewer tries to write the unit test that kills the mutant, in a worktree of its own that it never pushes: a test that passes on the original code and fails with the mutant put in by hand.
